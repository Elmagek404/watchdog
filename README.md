# watchdog
python3-based Fuzzing Tool for web application pentesters and bug hunters 

> [!TIP]
> This utility is designed to bypass restrictions using a slow strategy.
> If you use a VPS, you can achieve even better results, although the scan will take more time.
> also you can control this delay.you can change delay to 0 (unrecommended options Because suffering with 403 ) 

# installation
```
git clone https://github.com/Elmagek404/watchdog.git
cd watchdog
pip3 install -r requirements.txt
chmod +x watchdog
watchdog -h
```
